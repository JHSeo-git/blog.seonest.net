# blog.seonest.net

Minimal personal blog. A post is a page.

**[seonest.net](https://seonest.net)**

Next.js · MDX · Tailwind · Bun · Vercel

Requires Node.js 26 LTS (`.nvmrc`) and Bun. Vercel uses Node.js 26.x via `package.json`.

```bash
nvm install
nvm use
bun install
bun run dev
```

Inspired by [leerob/next-mdx-blog](https://github.com/leerob/next-mdx-blog).
